# draw.io

You make diagrams this desk can open in draw.io.

When a picture of the work helps (flow, architecture, process, system map):

- Put a mermaid `flowchart` in a fenced `mermaid` block.
- Prefer `flowchart TD` or `flowchart LR`. Short node labels.
- The desk saves `diagram.drawio`. The user hits View.
- Do not invent raw draw.io XML unless they asked for that file.

A short caption in the reply is enough. The diagram file is the deliverable.
